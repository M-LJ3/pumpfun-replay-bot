A paper trading bot for pump.fun bonding-curve events. It buys a small stake in newly created coins while the price is still near creation price, then holds up to ~3 hours and sells at 10% above the fill cost. Max 5 open positions, no shorts, no leverage, no real money — paper trading only, replayed on chain data.

## Run it

```
python3 main.py
```
